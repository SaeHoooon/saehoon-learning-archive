Architecture Basics

Architecture란?

신경망의 architecture는 크게 세 가지를 결정한다. layer의 개수인 depth, 각 layer의 unit 수인 width, 그리고 layer 사이의 연결 방식이다.

DEPTHLayer를 몇 개 쌓을 것인가
WIDTH각 layer에 unit을 몇 개 둘 것인가
CONNECTIVITYLayer를 어떻게 연결할 것인가
x→h(1)→h(2)→⋯→y

가장 기본적인 feedforward neural network는 위와 같은 chain structure를 가진다.

Eq. 6.40
\[ h^{(1)} = g^{(1)}\!\left(W^{(1)T}x+b^{(1)}\right) \]
Eq. 6.41
\[ h^{(2)} = g^{(2)}\!\left(W^{(2)T}h^{(1)}+b^{(2)}\right) \]
이전 layer→Affine transformation→Activation
예시

\(x\in\mathbb{R}^{100}\rightarrow h^{(1)}\in\mathbb{R}^{50}\rightarrow h^{(2)}\in\mathbb{R}^{20}\rightarrow y\in\mathbb{R}^{10}\) 이라면 hidden layer는 2개이며 width는 각각 50, 20이다.

KEY MESSAGE

hidden layer 하나만으로도 매우 많은 함수를 표현할 수 있지만, 실제로는 깊은 network가 더 적은 unit과 parameter로 같은 함수를 표현할 수 있는 경우가 많다.

반대로 depth가 증가하면 optimization은 더 어려워질 수 있다. 따라서 실제 depth와 width는 이론만으로 정하지 않고 validation error를 확인하면서 실험적으로 결정한다.

6.4.1

Universal Approximation Properties and Depth

왜 hidden layer가 필요한가?

Linear model은

\[y=W^Tx+b\]

형태이므로 본질적으로 linear function만 표현한다. optimization은 비교적 쉽지만, 현실의 복잡한 nonlinear 관계를 표현하기에는 한계가 있다. 그래서 hidden layer에 nonlinear activation을 사용한다.

Input→Nonlinear hidden layer→Output

Universal Approximation Theorem

충분한 수의 hidden unit과 적절한 nonlinear activation을 가진 feedforward network는 매우 넓은 종류의 함수를 원하는 정확도까지 근사할 수 있다. 초기 결과는 sigmoid 같은 squashing function을 중심으로 제시되었고, 이후 ReLU를 포함한 더 넓은 activation class로 확장되었다.

UNIVERSAL APPROXIMATION hidden layer가 1개라도 충분히 넓다면 복잡한 함수를 근사할 수 있다.

표현 가능성과 학습 가능성은 다르다

Representable원하는 함수를 나타내는 parameter가 network 안에 존재한다.
≠
Learnabletraining algorithm이 실제로 그 parameter를 찾아낸다.

실제 training에서는 optimization이 적절한 parameter를 찾지 못하거나, training data에 과적합된 다른 함수를 선택할 수 있다.

주의

Universal Approximation Theorem은 “신경망이 무엇이든 자동으로 학습한다”는 보장이 아니다. 원하는 함수를 근사하는 parameter configuration이 존재한다는 표현 능력에 관한 정리다.

03

Why Depth?

hidden layer 하나면 충분한데 왜 Deep Learning을 쓰는가?

Universal Approximation Theorem만 보면 hidden layer 하나면 충분해 보인다. 문제는 같은 함수를 표현하기 위해 필요한 width가 매우 커질 수 있다는 점이다.

입력이 \(v\in\{0,1\}^n\)인 \(n\)개의 binary variable이라면 가능한 입력 조합은

\[2^n\]

개다. 일반적인 함수를 모두 표현하려면 최악의 경우 \(O(2^n)\) 규모의 자유도가 필요할 수 있으므로 shallow network가 지수적으로 커질 수 있다.

Piecewise linear network와 linear region

ReLU는

\[g(z)=\max(0,z)\]

이므로 network는 입력 공간을 여러 linear region으로 나눌 수 있다. depth가 증가하면 기존 영역을 단순히 추가하는 것이 아니라 앞선 layer가 만든 표현을 다음 layer가 다시 조합하면서 훨씬 복잡한 구분을 만들 수 있다.

Eq. 6.42
\[ O\!\left(\binom{n}{d}^{d(l-1)}n^d\right) \]
d input dimension l network depth n units per hidden layer
INTERPRETATION

식의 세부 상수보다 중요한 것은 linear region의 수가 depth \(l\)에 대해 매우 빠르게, 경우에 따라 exponential하게 증가할 수 있다는 점이다.

Maxout에서도 같은 현상

각 maxout unit이 \(k\)개의 filter를 가진다면 linear region의 수는 다음과 같은 형태로 증가할 수 있다.

Eq. 6.43
\[ O\!\left(k^{(l-1)+d}\right) \]

핵심은 동일하다. depth가 증가하면 적은 unit으로도 더 복잡한 함수를 효율적으로 표현할 가능성이 커진다.

Depth의 통계적 의미

deep architecture를 선택한다는 것은 복잡한 함수가 여러 단순한 함수의 계층적 합성(composition)으로 이루어져 있을 것이라는 가정을 모델에 넣는 것과 같다.

Pixel→Edge→Corner / Shape→Object Part→Object
\[f(x)=f^{(L)}\!\left(f^{(L-1)}\!\left(\cdots f^{(1)}(x)\right)\right)\]

shallow network의 parameter 수만 늘리는 경우와 실제 depth를 늘리는 경우를 비교한다. 단순한 parameter 증가만으로는 depth 증가와 같은 성능 향상이 나타나지 않았다.

CONCLUSION Depth의 효과 ≠ 단순한 parameter 수 증가

depth는 “복잡한 함수가 단순한 함수들의 계층적 합성으로 이루어져 있다”는 구조적 prior를 제공한다.

6.4.2

Other Architectural Considerations

실제 neural network는 단순한 chain보다 훨씬 다양한 연결 구조를 사용할 수 있다.

Skip Connection

h(1)→h(2)→h(3)
↘──────────────↗

바로 다음 layer로만 연결할 필요는 없다. 중간 layer를 건너뛰는 연결을 만들 수 있으며, 이런 연결은 output에서 input에 가까운 layer까지 gradient가 흐르기 쉽게 만드는 데 도움을 줄 수 있다.

Fully Connected일 필요도 없다

기본 layer \(h=W^Tx+b\)는 이전 layer의 모든 neuron과 다음 layer의 모든 neuron을 연결한다. 하지만 문제의 구조에 따라 일부 연결만 허용할 수 있다.

FULLY CONNECTED
모든 unit이 연결
SPARSE CONNECTION
필요한 연결만 사용

연결을 제한하면 parameter와 computation을 줄일 수 있다. 대표적인 예가 CNN의 local connectivity다.

DESIGN PRINCIPLE

좋은 architecture는 문제의 구조에 맞는 connectivity를 사용한다.
